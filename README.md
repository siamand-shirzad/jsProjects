# JavaScript Mini Projects

Vanilla JavaScript practice pages:

- **Order Coffee** — order form with an overlay summary
- **Drink Order** — drink ordering page
- **Personal Form** — customer list with add/remove, search by email and simple filters
- String-method exercises

تمرین‌های جاوااسکریپت خالص.

## Run
Open `index.html` in a browser; the projects are under `assets/pages/`.
